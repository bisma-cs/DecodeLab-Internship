# Data Science Project 1
## Advanced EDA & Feature Engineering

### Objective
The objective of this project is to clean and transform a raw dataset
using statistical techniques and feature engineering.

### Dataset
The dataset contains 1200 e-commerce order records.

### Tasks Completed

- Dataset exploration
- Missing value analysis
- Statistical imputation
- Outlier detection using IQR
- Outlier handling
- Exploratory Data Analysis
- Feature engineering
- Correlation analysis
- Clean dataset export

### Features Created

1. OrderYear
2. OrderMonth
3. AverageItemValue
4. CartValue
5. OrderDayOfWeek

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Result

The raw dataset was cleaned and transformed into a dataset
suitable for further data analysis and machine learning.
